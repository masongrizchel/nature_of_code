This repository contains Python implementations of the foundational Processing examples from the Introduction of The Nature of Code by Daniel Shiffman. It serves as a starting point for simulating natural systems and motion through code.

The notebooks in this repository cover:
* Random Walks: Basic algorithms used to model real-world phenomena through a series of random steps.
* Probability & Distributions: Techniques for moving beyond uniform randomness by implementing non-uniform probabilities, custom distributions, and Gaussian (normal) distributions.
* Perlin Noise: Algorithms for generating naturally ordered, smooth sequences of pseudo-random numbers to create organic behaviors and textures.

All original Processing setup() and draw() loops have been adapted into iterative Python scripts optimized for Jupyter Notebooks, utilizing matplotlib for visualization.
